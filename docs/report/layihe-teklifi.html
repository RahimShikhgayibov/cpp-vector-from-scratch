Problem statement

Dinamik massiv proqramlaşdırmada ən çox istifadə olunan məlumat strukturudur: elementləri yaddaşda ardıcıl saxlayır, O(1) indeksləmə verir və lazım olduqca böyüyür. C++-da onu std::vector təmin edir. İstifadəsi asandır, amma düzgün implementasiyası obyektin ömrünün əl ilə idarəsini, xam yaddaşı, rule of five-ı, move semantics-i və exception safety-ni tələb edir. Layihədə std::vector-un tam işlək analoqu sıfırdan yazılacaq, düzgünlüyü testlərlə sübut olunacaq və xüsusiyyətləri ölçmə ilə tədqiq ediləcək.

Məqsədlər

  1. mystl::vector<T>: std::vector-un bütün interfeysi (custom allocator və vector<bool> xaric).
  2. Mərhələli təkamül (v1–v5): hər versiya əvvəlkinin konkret problemini həll edir.
  3. Düzgünlüyün sübutu: unit testlər, std::vector ilə differential test, sanitizer-lər.
  4. Aşağıdakı 7 tədqiqat sualına ölçülmüş cavab.

Tədqiqat sualları

  1. push_back həqiqətən amortized O(1)-dirmi?
  2. Böyümə faktoru 2× və 1.5×: hansı yaxşıdır?
  3. reserve nə qədər qazandırır?
  4. Copy ilə move fərqi nədir; noexcept unudulanda nə baş verir?
  5. Ortaya insert/erase praktikada nə qədər bahadır?
  6. Cache-in təsiri nə qədərdir (vector və linked list traversal)?
  7. Nəticə std::vector-a nə qədər yaxındır?
